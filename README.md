# Sarwar Ali — Portfolio

Personal portfolio of Sarwar Ali: AI automation developer, data analyst, vibe coder and graphic design instructor from Thatta, Sindh.

Static site (HTML, CSS, vanilla JS), no build step.

- `index.html`: page markup
- `styles.css`, `script.js`: paper-gun hero and slip animation
- `sections.css`, `sections.js`: About, Services, Work, Experience, Skills, Certifications, Contact
- `assets/`: photos and CV preview
- `cv/`: CV PDF

Run locally: open `index.html`, or `python3 -m http.server` in this folder.
